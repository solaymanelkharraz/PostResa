# PostResa - Next Version Roadmap (v2.0)

1. **Sub-Admins & Permission Scopes**
   - Allow School Admins to create Sub-Admins.
   - Assign custom permission scopes/action access per Sub-Admin (e.g., Post Moderator, Reservation Manager, User Manager).

2. **Advanced & Reverse Reservation Engine**
   - Full Reservation Engine enhancements.
   - Reverse Reservations: Allow Admins/Profs to assign spaces directly to specific student groups or classes.
   - Auto-sync space reservations directly into students' group schedules.

3. **Real-Time WebSockets & Live Alerts**
   - Live WebSockets for direct & group messaging.
   - Instant push notifications for post approvals and reservation updates.

4. **PDF Exports & Analytics**
   - Export printable PDF schedules for groups and spaces.
   - Space usage analytics dashboard.
